## Short Description
The Apple Silicon continuation of the classic native Markdown editor for macOS, featuring built-in Model Context Protocol (MCP) support, instant AppKit rendering, and zero telemetry.

## Long Description
MacDown SE (Silicon Edition) modernizes the beloved MacDown editor for Apple Silicon. Rewritten and hardened for macOS Monterey through macOS Sonoma and beyond, MacDown SE runs as an exclusive native arm64 binary without Rosetta translation.

MacDown SE introduces native Model Context Protocol (MCP) server integration via `macdown-se --mcp`, allowing local AI models and agents to inspect and edit active document buffers in real time. It fixes legacy AppKit split-view restoration bugs, handles CommonMark list formatting, and provides live synchronized dual-pane rendering with zero telemetry and zero cloud lock-in.
