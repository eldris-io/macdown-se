## Short Summary

## Full Description
MacDown SE is a fast, lightweight Markdown editor engineered natively for Apple Silicon. Built on Cocoa and AppKit, it launches in under 120 milliseconds and features real-time preview synchronization, TeX math rendering via MathJax, syntax highlighting for over 50 languages via Prism, and customizable CSS styling.

With built-in Model Context Protocol (MCP) support, MacDown SE bridges native document editing with local AI assistants, enabling secure, sovereign AI workflows without monthly subscriptions or cloud tracking.

## What is New in Version 1.0.0
